# Layout gravity wells

Defaults a generator drifts into when nobody decided the layout. Check every pick against this
list and name any well it still contains. Keeping one deliberately is fine — write down why.

| Well | Looks like | Why it fails | Resist with |
|---|---|---|---|
| Header as hero | Name left, badge right, then content | The most important object sits below the line of attention | Put the key figure or featured item in the top band; identity becomes the caption |
| Equal-card grid | Three or four identical boxes in a row | Says every fact matters equally, so none does | Weight by importance: 60/40, 2:1:1, one wide tile — see *bento* and *40/60 split* in [`layout-vocabulary.md`](../../boxel-design/references/layout-vocabulary.md) |
| Identical tiles | N same-size items regardless of rank or state | Hides the story the data tells — tier, urgency, rarity | Group with headings, vary span by rank, promote the first row; for images, *masonry* in [`layout-vocabulary.md`](../../boxel-design/references/layout-vocabulary.md) |
| Form above content | Input panel first, results under it | The result is the point; the form is a tool | Make the input the screen for an operator, or move it to a rail |
| Dropdown as primary control | Full-width select that changes everything | Reads as a form field, not a decision | A chip, a segmented control, or a rail with the current choice visible |
| Table as default list | Every collection is a table | Tables suit evidence, not browsing or choosing | Shelf, rail, magazine or grouped rows, by the job (named moves: [`layout-vocabulary.md`](../../boxel-design/references/layout-vocabulary.md)) |
| Settings panel for a ritual | A scheduled action as a labelled box with a button | No sense of when | Attach the action to a date on a strip or calendar |
| Sidebar by habit | Left nav because apps have one | Costs 20% of width for four destinations | Tabs in the top bar until there are more than seven |
| Centre everything | Every block and heading centred | No reading order | Left-align text; centre only the one spotlight object |
| Disabled-button wall | Many greyed buttons with the same reason | A wall of failure | One contextual prompt; hide the action until it can work |
| Empty state as apology | "No items yet." | Nothing to do next | Name the first action and what will appear |
| Same padding everywhere | One spacing value for hero, cards and rows | No rhythm, no grouping | Bigger gaps between groups than inside them |
| Uniform radius and shadow | Every box rounded and lifted alike | Everything floats, nothing is grounded | Radius and elevation by role — containers flat, actionable items lifted — see *layered surface* in [`layout-vocabulary.md`](../../boxel-design/references/layout-vocabulary.md) |
| Stock photo tile | Image, title, price, button, repeated | E-commerce default, forgettable | Let the style decide the media treatment: cut-out, tinted, framed, or none |
